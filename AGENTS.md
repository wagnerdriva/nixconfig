# Repository instructions

- After completing a task and running the relevant checks, commit its changes and push the current branch to its upstream remote by default. Do not ask for confirmation unless the user explicitly restricted committing or pushing.
- Commit only changes belonging to the task; preserve unrelated pending work. Never force-push by default.
- If a check, commit, or push fails, resolve the problem when possible and clearly report any remaining blocker. Include the commit hash and push status in the final response.
